Rate Ninja API

The browser uses same-origin session endpoints. Rate data is served from SQLite on the server and is not exposed as a raw database file. Copy-paste requests, with placeholders, are the example blocks in the partner and MCP guide and API-README.md. This page does not contain a key, client secret, token, or password.

Three ways to read rates

AccessCredentialPrices
Same-origin session HTTP-only cookie rate_ninja_session A contract owner sees base contract prices. A customer sees each active linked owner's rates with that customer's margin.
Demo API /api/v1/* Shared X-API-Key. The server variable is RATE_NINJA_API_KEY. Send X-API-Key: YOUR_DEMO_API_KEY. Base contract prices for the demo database. This is not a company's private credential and it is not accepted on the partner API or MCP.
Partner API and POST /mcp OAuth bearer token from a contract-owner approval. Header Authorization: Bearer YOUR_ACCESS_TOKEN. That owner's base contract prices. Predictive results are estimates of the base price, not a customer margin and not a stored rate.

A customer account (company type Freight Forwarder/Customer) cannot authorize the partner API or MCP. Only a contract owner (company type Contract Owner) can. Partner OAuth, the partner routes, and MCP run only when PARTNER_OAUTH_ENABLED allows them: true is on, false is off, and unset is on unless NODE_ENV is production. On 2026-10-13 the operator confirmed that production is running with the gate open.

rate20D is number or null (no price on file). rate40D is number or null (no price on file). rate40HC is number or null (no price on file). A stored 0 stays 0. A missing base stays null on a predictive estimate.

{ "rate20D": 1000, "rate40D": null, "rate40HC": null }

Demo API

The limit on the three data routes is 60 requests per 60-second window for the whole server process. GET /api/v1 returns the endpoint list and does not check the key. Open the testbed to call the demo routes locally.

EndpointAccessPurpose
GET /api/v1/ratesDemo API keyBase rates. Optional carrier, originPort, destinationPort are case-insensitive substrings. page defaults to 1 (ceiling 10000). pageSize defaults to 50 (ceiling 100).
GET /api/v1/sailingsDemo API keyRequires carrier, originPort, and after. Carrier and departure port are case-sensitive exact matches. No pagination.
GET /api/v1/predictive-pricingDemo API keyRequires carrier, originPort, and after more than 90 days ahead. Base-price estimate. Not stored. No pagination.

Connection, revocation, rate limits, and every tool argument are in the partner and MCP guide. Revoke a grant on Connected apps or with POST /oauth/revoke. Sample calls use YOUR_ACCESS_TOKEN, YOUR_CLIENT_ID, and YOUR_CLIENT_SECRET as placeholders.

Partner list filters are case-insensitive exact matches. page defaults to 1 and pageSize defaults to 50, with ceilings 10000 and 100. Predictive after is required and must be more than 90 days ahead; carrier and originPort are optional. MCP protocol versions are 2025-11-25 (default) and 2025-03-26. The demo key is not a bearer token.

Keep SESSION_SECRET and RATE_NINJA_API_KEY out of the browser and source control.
